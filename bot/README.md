# 🤖 OceanMove Bot — Telegram-помощник студии

Бот работает на твоём сервере **n8n**. Он умеет:

- 🔔 Каждое утро в 10:00 присылать тебе дайджест: занятия сегодня, пробные, продления абонементов (данные из CRM/Firebase)
- 🌊 Напоминать в чатах групп родителей о занятии в день занятия
- 💬 Отвечать на команды: `/today`, `/trials`, `/renewals`, `/id`

## Файлы

| Файл | Что это |
|------|---------|
| `n8n/oceanmove-daily.json` | Воркфлоу «утренний дайджест + напоминания в группы» (по расписанию, 10:00 МСК) |
| `n8n/oceanmove-commands.json` | Воркфлоу «команды бота» (отвечает на сообщения) |

## Установка (один раз, ~10 минут)

### Шаг 1. Создай бота в Telegram

1. Открой в Telegram [@BotFather](https://t.me/BotFather)
2. Отправь `/newbot`
3. Придумай имя, например: `Движение Океана — помощник`
4. Придумай username, например: `oceanmove_helper_bot`
5. BotFather пришлёт **токен** вида `1234567890:AAE...` — скопируй его

### Шаг 2. Добавь токен в n8n

1. В n8n: **Credentials → Add credential → Telegram API**
2. Вставь токен из шага 1, сохрани (назови, например, «OceanMove Bot»)

### Шаг 3. Импортируй воркфлоу

1. В n8n: **Workflows → Import from File** (или три точки → Import)
2. Импортируй оба файла из папки `bot/n8n/`
3. В каждом воркфлоу открой Telegram-ноды («Отправить в Telegram», «Ответить», «Команда в Telegram») и выбери credential из шага 2
4. **Активируй** воркфлоу «OceanMove — команды бота» (переключатель Active)

### Шаг 4. Узнай chat id

1. Напиши своему боту в личку `/id` — он ответит числом. Это твой **ADMIN_CHAT_ID**
2. Добавь бота в групповые чаты родителей (если нужны напоминания в группах) и отправь там `/id`
   - ⚠️ Чтобы бот видел команды в группах: в BotFather → `/setprivacy` → выбери бота → **Disable**
   - Chat id групп — отрицательные числа вида `-100123456789`, это нормально

### Шаг 5. Впиши chat id в дайджест

1. Открой воркфлоу «OceanMove — утренний дайджест», ноду **«Собрать сообщения»**
2. В начале кода впиши id:
   ```js
   const ADMIN_CHAT_ID = '123456789';   // твой id из шага 4
   const GROUP_CHATS = {
     'Малыши': '-100...',    // id чата группы, или '' если чата нет
     'Младшие': '-100...',
     'Средние': '',
     'Подростки': '',
   };
   ```
   Пустые `''` — просто пропускаются, ошибок не будет.
3. Сохрани и **активируй** воркфлоу

### Шаг 6. Проверь

- Нажми **Execute workflow** в дайджесте — тебе должно прийти сообщение
- Напиши боту `/today` — должен ответить задачами на сегодня

## Команды бота

| Команда | Что делает |
|---------|-----------|
| `/today` (или `/сегодня`) | Занятия, пробные и продления на сегодня |
| `/trials` (или `/пробные`) | Ближайшие записи на пробные по дням |
| `/renewals` (или `/продления`) | Кому пора продлить абонемент (с телефонами) |
| `/id` | Chat id текущего чата (для настройки) |
| `/help` | Список команд |

## Как это работает

```
n8n (твой сервер)
 ├─ по расписанию 10:00 МСК ──→ Firebase (crm.json) ──→ дайджест тебе + напоминания в группы
 └─ команда в Telegram ──→ Firebase (crm.json) ──→ ответ в чат
```

Бот читает **ту же базу Firebase**, что и CRM — ничего дублировать не нужно.
Логика продлений идентична `isAbonementEndToday()` в `crm.html`.
Расписание занятий — зеркало `CLAUDE.md` (при изменении расписания обновить в обоих воркфлоу).

## 🤖 AI-ассистент для родителей (второй бот)

Кроме служебного бота есть **разговорный AI-ассистент**: родители пишут ему обычным текстом, нейросеть отвечает, консультирует по расписанию и **сама записывает на пробное**. Готовая заявка падает сразу в два места: в CRM (раздел «Заявки из бота») и в Google-таблицу.

### Файлы

| Файл | Что это |
|------|---------|
| `n8n/oceanmove-assistant.json` | Главный воркфлоу: Telegram → YandexGPT → ответ (память диалога в Firebase `/chats`) |
| `n8n/oceanmove-save-lead.json` | Под-воркфлоу «сохранить заявку»: пишет в Firebase `/inbox` + Google-таблицу |

Мозг бота — **YandexGPT** (Яндекс Облако), потому что OpenRouter/зарубежные LLM блокируют запросы из России. YandexGPT хорошо говорит по-русски, работает из РФ и оплачивается рублёвой картой (новым пользователям — бесплатный грант).

### Что нужно из Яндекс Облака

1. **Folder ID** — идентификатор папки `default` (вид `b1g...`), виден вверху консоли рядом с папкой.
2. **API-ключ** сервисного аккаунта с ролью `ai.languageModels.user`:
   [console.yandex.cloud](https://console.yandex.cloud) → Service accounts → создать аккаунт → добавить роль `ai.languageModels.user` → Create new key → **API key** → скопировать секрет.

Folder ID уже прописан в воркфлоу (нода «Собрать запрос», строка `modelUri`). Если папка другая — поменяй там.

### Установка

1. **Header Auth для YandexGPT**: в n8n **Credentials → Add → Header Auth**:
   - **Name**: `Authorization`
   - **Value**: `Api-Key ТВОЙ_API_КЛЮЧ` (именно с префиксом `Api-Key ` и пробелом)
   Назови, например, `YandexGPT`.
2. **Google-таблица**: создай пустую таблицу в Google Sheets с колонками: `Дата, Ребёнок, Возраст, Родитель, Телефон, Группа, Комментарий, Источник`. В n8n подключи **Google Sheets** credential (OAuth).
3. **Импортируй** оба файла из `bot/n8n/`.
4. В `oceanmove-save-lead`: в ноде «В Google-таблицу» выбери свой credential, свою таблицу и лист. (Firebase работает сразу.)
5. В `oceanmove-assistant`:
   - выбери Telegram credential в триггере и в ноде «Ответить родителю»
   - в ноде **YandexGPT** выбери Header Auth credential из шага 1
   - в ноде **Сохранить заявку** выбери воркфлоу «OceanMove — сохранить заявку»
   - в ноде **Собрать запрос** впиши **цены и адрес** (место помечено `ЗАПОЛНИ_ЗДЕСЬ`)
   - активируй воркфлоу
6. Напиши боту от лица родителя — он ответит и, собрав имя/возраст/телефон, создаст заявку.

### Как заявки попадают в CRM

```
Родитель ─► YandexGPT ─► заявка ─┬─► Firebase /inbox ─► CRM: «📨 Заявки из бота» ─► [Добавить] ─► клиент 'new'
                                 └─► Google-таблица (твой журнал)
```

Заявки пишутся в отдельную ветку Firebase `/inbox` — это **безопасно**, основная база клиентов не перезаписывается. В CRM в разделе «Напоминания» сверху появляется блок «📨 Заявки из бота»: жмёшь **✅ Добавить в клиенты** — создаётся клиент со статусом `new` (канал «Telegram-бот»), заявка исчезает из очереди. Кнопка 🗑️ — удалить спам.

### Память диалога

Бот помнит переписку с каждым родителем: история хранится в Firebase `/chats/<chat_id>` (последние 16 сообщений). Никакой отдельной базы не нужно.

### Сменить модель

В ноде «Собрать запрос», в `modelUri`: `yandexgpt-lite` (дёшево/быстро, по умолчанию) или `yandexgpt` (умнее, дороже). Формат: `gpt://<folder_id>/yandexgpt-lite/latest`.

## Планы на развитие

- Напоминание за 2 часа до занятия (второй Schedule Trigger в 16:00)
- Кнопки в дайджесте («позвонила», «продлили»)
- Запись на пробное прямо через бота (родитель пишет боту → клиент появляется в CRM)
- Еженедельная статистика (сколько пробных, конверсия в покупку)
